# Birdhouse

A bird-themed engine-building card game for the browser.

## Stack

React 19 (with React Compiler) · TypeScript · Vite · Tailwind CSS v4 · oxlint

## Getting started

```sh
npm install
npm run dev
```

## Scripts

| Command           | Purpose                       |
| ----------------- | ----------------------------- |
| `npm run dev`     | Start the dev server          |
| `npm run build`   | Type-check and build          |
| `npm run lint`    | Lint with oxlint              |
| `npm run preview` | Serve the production build    |
